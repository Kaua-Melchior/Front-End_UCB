Repositório oficial das aulas e projetos de **Desenvolvimento Front-End** do curso de Engenharia de Software da UCB (Universidade Católica de Brasília), desenvolvido por **Kauã Melchior**.

Este projeto atua como um *Hub* central, apresentando uma interface moderna e responsiva (com efeitos de *Glow Hover* e renderização dinâmica) para navegar por todas as aulas práticas e atividades desenvolvidas ao longo do semestre.

---

## 📚 Aulas e Projetos Desenvolvidos

O hub centraliza as seguintes práticas (cujos cards são gerados dinamicamente via JavaScript):

- **Aula 01 (25 de Março):** Introdução à Estrutura Básica e HTML.
- **Aula 02 (01 de Abril):** Variáveis CSS e Estilização Inicial.
- **Aula 03 (08 de Abril):** Posicionamento e Layout Moderno.
- **Aula 04 (22 de Abril):** Práticas Avançadas de Componentização.
- **Aula 05 (06 de Maio):** Design Responsivo e Adaptação Mobile.
- **Aula 06 (14 de Maio):** Criação da Landing Page *RichardsIAF*.
- **Aula 07 (20 de Maio):** Estrutura Inicial do Projeto *Happy*.
- **Aula 08 (27 de Maio):** Mapas Interativos, UI e Animações avançadas no projeto *Happy*.

---

## 🛠️ Tecnologias e Técnicas Utilizadas

- **HTML5:** Estrutura semântica das páginas e formulários.
- **CSS3:** 
  - Estilizações avançadas e Design Responsivo (Media Queries).
  - Variáveis CSS (Custom Properties) para temas e manutenibilidade.
  - Flexbox & CSS Grid.
  - Animações fluidas, transições e micro-interações.
  - Efeitos modernos de UI como *Glassmorphism* e *Glow Effect*.
- **JavaScript (Vanilla):**
  - Manipulação da DOM.
  - Renderização dinâmica do conteúdo do Hub central.
  - Event Listeners dinâmicos (efeitos de mouse tracking).

## 🚀 Como executar este projeto

Como trata-se de um projeto Front-End estático, você não precisa de configurações complexas para visualizá-lo:

1. Clone o repositório para sua máquina:
   ```bash
   git clone https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd NOME_DO_REPOSITORIO
   ```
3. Abra o arquivo `index.html` em qualquer navegador moderno.
   *(Dica: Se utilizar o VS Code, a extensão **Live Server** é recomendada para melhor visualização durante alterações).*
